# Bingo-Abend

Eine responsive, browserbasierte Bingo-Oberfläche auf Deutsch. Spieler registrieren sich mit ihrem vollständigen Namen, erstellen einen Raum mit einem zufälligen vierstelligen Code oder treten einem Raum bei und spielen anschließend auf einer zufällig generierten Bingo-Karte.

## Lokal starten

```bash
npm start
```

Die Anwendung ist ein Frontend-Prototyp. Mehrspieler werden im Warteraum simuliert; für echte geräteübergreifende Räume wäre zusätzlich ein Echtzeit-Backend erforderlich.
